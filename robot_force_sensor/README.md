# robot_force_sensor

ROS2 packages for the ABB force sensor on the IRB6700 cell.

- **abb_force_sensor_description** — URDF/xacro geometry (sensor + adapter plate)
  inserted between `tool0` and the SWK-160 tool changer.
- *(planned)* interface/driver package for reading force/torque data from the
  sensor in ROS2.
